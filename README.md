This project builds a predictive model to identify customers who are likely to purchase holiday packages using booking behavior data.

## Objective
To support proactive marketing by predicting holiday purchases before travel.

## Dataset
Customer booking data including passenger count, booking lead time, route, and ancillary preferences.

## Methodology
- Data cleaning and preprocessing
- One-hot encoding of categorical variables
- Logistic Regression model
- Model evaluation using Accuracy and ROC-AUC
- Feature importance analysis

## Key Insights
- Route is the strongest predictor of holiday purchase
- Customers who plan early and select ancillaries are more likely to convert
- Model achieved ~85% accuracy and ~0.79 ROC-AUC
